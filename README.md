# Retail Sales Insights

An Excel-based data analysis project focused on transforming raw retail data into meaningful business insights using **Microsoft Excel**.

The project analyzes customers, products, sales transactions, and product information to answer practical business questions and identify trends in sales performance.

---

## Project Overview

This project was completed as an **Excel Minor Project** involving multiple datasets and a series of analytical questions.

The objective was to:

* Analyze retail sales performance
* Extract useful business insights from raw data
* Perform data validation and lookups
* Identify top-performing products and customers
* Analyze regional and category-level performance
* Work with dates, quantities, prices, and revenue
* Use Excel-based analytical techniques to solve business questions

---

## Dataset

The project contains multiple interconnected datasets, including:

### Customers

Contains customer-related information such as:

* Customer ID
* Customer Name
* City
* Region
* Other customer attributes

### Products

Contains product information such as:

* Product ID
* Product Name
* Category
* Price
* Product status

### Sales

Contains transactional information such as:

* Transaction ID
* Customer ID
* Product ID
* Quantity
* Sale Date
* Sales amount

## Analysis Performed

The project covers several types of Excel analysis.

### 1. Data Analysis

* Total sales calculations
* Quantity analysis
* Revenue calculations
* Average sales values
* Customer-level analysis
* Product-level analysis

### 2. Lookup & Data Validation

Used Excel lookup techniques to connect information across different datasets and identify relationships between:

* Customers and transactions
* Products and transactions
* Product IDs and product information

### 3. Business Analysis

The analysis answers questions related to:

* Top-selling products
* Highest-value customers
* Sales by category
* Regional performance
* Transaction trends
* Product performance
* Customer purchasing behavior

### 4. Pivot Analysis

Pivot-style analysis was used to summarize large amounts of transactional data and make comparisons easier.

The supporting analysis can be found in:

`Pivot_Analysis`

### 5. Helper Calculations

Additional calculations required for solving the questions are organized in:

`Analysis_Helper`

This keeps the original datasets separate from the analytical calculations.

## Key Approach

The analysis followed a simple workflow:

```text
Raw Data
   ↓
Data Understanding
   ↓
Data Validation
   ↓
Lookup & Calculations
   ↓
KPI Analysis
   ↓
Pivot Analysis
   ↓
Business Insights
```

The goal was not only to calculate answers but also to maintain a clear separation between the **original data** and the **supporting analysis**.
